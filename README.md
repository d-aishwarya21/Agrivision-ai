# CausalAg-Net — AI Crop Disease Diagnosis

A full-stack AI-powered plant disease detection system.

## Tech Stack
- Frontend: Next.js (TypeScript)
- Backend: FastAPI (Python)
- Database: SQLite
- AI: Neuro-symbolic logic engine with heatmap explainability

## How to Run
### Backend
cd backend
venv\Scripts\Activate.ps1
uvicorn main:app --reload --port 8000

### Frontend
cd frontend
npm run dev

Open http://localhost:3000
